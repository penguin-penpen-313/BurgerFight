# つみつみバーガー

スマホ向け・協力型ハンバーガー積みゲーム。GitHub Pages + Firestore で動作。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | プレイヤー用ページ |
| `master.html` | マスター用ページ（タイトルに制限時間と「プレイ」） |
| `js/game.js` | ゲーム本体（物理演算・採点・描画） |
| `js/app.js` | 画面遷移・チュートリアル・Firestore 同期 |
| `js/firebase-config.js` | Firebase の接続設定（要編集） |
| `css/style.css` | 画面デザイン |
| `firestore.rules` | Firestore セキュリティルール |

## セットアップ

1. Firebase コンソールでプロジェクト作成
2. **Firestore Database** を作成（本番モード）
3. Firestore → ルールに `firestore.rules` の中身を貼り付けて公開
4. プロジェクトの設定 → マイアプリ → ウェブアプリを追加 → 表示された値を `js/firebase-config.js` に記入
5. このフォルダをリポジトリに push → Settings → Pages で公開

ログイン・ユーザー登録は不要。

## 遊び方

- プレイヤー：`https://<ユーザー名>.github.io/<リポジトリ>/`
- マスター：`https://<ユーザー名>.github.io/<リポジトリ>/master.html`
- マスターが「プレイ」→ 全員に10秒カウントダウン → 同時スタート
  - 練習中・結果画面の人も強制的にカウントダウン開始
- 途中でページを開いた人は残り時間で参加
- 終了後は自分のスコアのみ表示
- マスターが「結果発表」を押すと全員の画面に合計スコアを表示
- 続けて「バーガー何個分」を表示（合計スコア ÷ 1000 ÷ 2、小数点以下切り捨て）
- 「練習」：時間制限・スコアなし。最初にチュートリアル（スキップ可）。左上「もどる」でいつでもメニューへ
- 別グループで同時に遊ぶ場合は `?room=名前` を全員のURLに付与（例：`master.html?room=team2`）

## ルール

- オーダー伝票の通りに具材を積む
- トップバンズをのせて約0.6秒安定すると完成 → 採点 → 次のオーダー
- 具材を画面外へ投げると消える（具材置きには上から補充）
- トレイを左右にスワイプして画面外へ出すと作り直し（同じオーダー）
- 2個完成ごとに具材が1つずつ増える（最大12＋バンズ2）

## 採点（1バーガー1000点満点）

| 項目 | 配点 | 内容 |
|---|---|---|
| 順番 | 500 | オーダーとの一致度（最長共通部分列）。余分・不足は減点 |
| きれいさ | 500 | 各層の横ズレと傾き |

- きれいさは順番の一致度に比例
- 下のバンズが無い場合は半分
- 個数が増えるほどオーダーが長くなるため、少数の上手い人より大人数の参加が有利

## 注意

- ログインなしのため、ルームの開始合図・結果発表はURLを知っていれば誰でも書き込める簡易仕様
- Firebase 未設定時は練習モードとして単独プレイ可能
